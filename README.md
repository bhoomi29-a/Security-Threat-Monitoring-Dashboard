# Security Threat Monitoring Dashboard

A web-based project designed to present security-related information through a clean and organized dashboard interface.

## Live Demo

[View Live Project](https://security-threat-monitoring-dashboard.onrender.com)

## Overview

The Security Threat Monitoring Dashboard is a web application built to provide an organized interface for viewing security-related information.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Run Locally

1. Clone this repository.
2. Install dependencies using `npm install`.
3. Start the application using `npm start`.
4. Open the local URL shown by the server in your browser.

## Deployment

The project is deployed using Render.
